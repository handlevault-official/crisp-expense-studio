# Crisp Expense Studio 💰

A local-first, offline-capable daily expense tracker and budget manager built for individuals, freelancers, and households. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **Daily Expense Logging:** Record transaction descriptions, amounts in Philippine Pesos (₱), categories, and dates.
- **Monthly Budget Overview:** Set customized monthly spending limits and track total spent vs. remaining budget in real-time.
- **Persistent Local Storage:** All records are saved securely inside your browser via `localStorage` with zero cloud tracking.
- **Dark & Light Themes:** Ergonomic high-contrast themes optimized for day and night use.
- **100% Offline & Private:** Runs entirely client-side without login walls or external servers.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, budget logic, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `.gitignore` — Ignored system and editor files.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
